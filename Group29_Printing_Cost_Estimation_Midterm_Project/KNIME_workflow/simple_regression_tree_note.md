# KNIME Regression Tree Note

In Python, the comparison model was implemented using `DecisionTreeRegressor`.

In KNIME, the equivalent regression-tree model used was **Simple Regression Tree Learner** and **Simple Regression Tree Predictor** because KNIME's regular Decision Tree Learner is for classification, while this project requires predicting a numerical value, `estimated_cost`.

Therefore, the Simple Regression Tree result in KNIME represents the Decision Tree Regressor comparison model for this predictive regression project.
